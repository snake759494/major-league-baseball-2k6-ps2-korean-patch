# 메이저리그 베이스볼 2K6 PS2 한글패치

PS2 북미판 **Major League Baseball 2K6 (SLUS-21235)**용 비공식 한국어 패치입니다. 메뉴, 옵션, 경기 HUD, 일시정지 메뉴, 도움말, 매뉴얼, 프랜차이즈 이메일·단장 메시지, 스카우트 리포트, 야구 퀴즈를 한국어로 바꿨습니다. **팀 이름과 선수 이름**도 한글로 나오며, 한국·일본·대만 선수는 우리식 전체 이름(박찬호, 이구치 다다히토, 왕젠밍)으로 잘리지 않게 표시합니다. PCSX2용 **16:9 와이드 패치**도 함께 배포합니다. 현재 배포판은 **v1.1 (2026-11-05)**입니다. v1.1은 흐린 날씨에서 경기 로딩 중 멈추던 문제를 고쳤습니다.

## 게임 소개 및 대상 버전

「Major League Baseball 2K6」는 2K Sports(Kush Games)가 2006년에 낸 메이저리그 야구 게임입니다. 시범 경기, 프랜차이즈, 시즌, 월드 베이스볼 클래식, 홈런 더비, 상황극 모드, 야구 퀴즈를 지원하며, 투구 결정구(Payoff Pitch)·인사이드 엣지 같은 시스템이 들어 있습니다.

이 패치는 **PS2 북미판 SLUS-21235의 DVD ISO**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

### Windows에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath ".\Major League Baseball 2K6 (USA).iso"
```

결과가 위 표의 MD5와 다르면 적용을 중단하세요. CHD, CSO, 압축 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `MLB_2K6_PS2_KO_v1.1.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구(예: xdelta UI)에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Major League Baseball 2K6 (USA) (Korean).iso`).
5. 결과 파일이 3.7GB이므로 저장할 드라이브에 여유 공간이 4GB 이상 있어야 합니다.

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s ".\Major League Baseball 2K6 (USA).iso" '.\MLB_2K6_PS2_KO_v1.1.xdelta' '.\Major League Baseball 2K6 (USA) (Korean).iso'
```

해시 검사까지 한 번에 하려면 `python tools/apply_release.py --xdelta xdelta3.exe --source "Major League Baseball 2K6 (USA).iso" --patch MLB_2K6_PS2_KO_v1.1.xdelta --output "Major League Baseball 2K6 (USA) (Korean).iso"`를 쓰세요.

### PCSX2에서 실행

결과 ISO를 PCSX2에서 엽니다. 원본판의 세이브 스테이트는 불러오지 마세요(실행파일 내용이 다릅니다). 메모리 카드 세이브는 원본판과 같은 형식이지만, 원본판에서 만든 로스터 세이브를 불러오면 선수 이름은 영문으로 남습니다.

## 16:9 와이드 패치 (PCSX2)

웹과 PCSX2 내장 패치 목록에 이 게임용 와이드 패치가 없어 새로 만들었습니다. 이 게임에는 원래 **16:9 모드가 숨어 있습니다.** PS2 본체 설정의 TV 화면이 16:9일 때만 켜지는데, 이 패치는 그 판정을 항상 16:9로 고정합니다. 그래서 화면을 가로로 늘리는 것이 아니라, 게임이 직접 넓은 시야로 그린 3D 화면과 16:9에 맞춘 메뉴가 나옵니다.

**한글패치 버전이 바뀌면 실행파일 CRC도 바뀌므로, 와이드 패치는 항상 같은 릴리즈의 pnach를 쓰세요.**

| 파일 | 대상 | 게임 CRC |
| --- | --- | --- |
| `SLUS-21235_42D69627.pnach` | 이 한글패치 v1.0·v1.1을 적용한 게임 | `42D69627` |
| `SLUS-21235_88BB9A5C.pnach` | 원본 북미판(영문) | `88BB9A5C` |

두 파일의 내용은 같습니다(고치는 위치가 두 판에서 같음). 파일 이름의 CRC만 다릅니다.

### 설치 (PCSX2 v2.x)

1. 릴리즈에서 자신의 게임에 맞는 `.pnach` 파일을 받습니다. 한글판이면 `SLUS-21235_42D69627.pnach`입니다. 파일 이름을 바꾸지 마세요(PCSX2는 이름의 CRC로 게임을 찾습니다).
2. PCSX2 `patches` 폴더에 넣습니다.
   - 설치판: `문서\PCSX2\patches\`
   - 휴대용판: `pcsx2-qt.exe`가 있는 폴더의 `patches\`
   - 폴더 위치는 **설정 → 폴더**에서도 확인할 수 있습니다.
3. 게임 목록에서 게임을 오른쪽 클릭 → **속성** → **패치** 탭을 엽니다.
4. **Widescreen 16:9** 항목에 체크합니다. 화면비는 패치가 자동으로 16:9로 바꿉니다.
5. 게임을 실행하면 화면에 "게임 패치 1개 활성화" 같은 알림이 나옵니다.

게임 안에는 따로 바꿀 화면 설정이 없습니다.

### 끄기·문제 해결

- 끄려면 4번의 체크를 해제하고, 화면비를 4:3으로 되돌립니다.
- 패치 탭에 항목이 보이지 않으면 파일 이름의 CRC와 게임의 CRC가 다른 것입니다. 게임을 실행한 뒤 **도구 → 로그 표시**에서 `CRC:` 줄을 확인하세요. 한글패치 v1.0·v1.1을 적용한 ISO면 `42D69627`, 원본이면 `88BB9A5C`가 나와야 합니다.
- 화면이 여전히 4:3이면 **설정 → 그래픽 → 화면비**를 16:9로 바꾸세요.
- 와이드 모드는 게임이 켜질 때 정해집니다. 실행 중에 체크를 바꿨다면 게임을 다시 시작하세요. 패치를 켠 상태에서 만든 세이브 스테이트를 패치를 끈 상태로 불러와도 비율이 섞일 수 있습니다.
- PCSX2 1.6 이하에서는 `cheats_ws` 폴더에 넣고 **와이드스크린 패치 사용**을 켜세요. 이 경우 `[Widescreen 16:9]` 줄을 지워야 할 수 있습니다.

### 알려진 한계

- 메뉴, 경기 설정 화면, 시범 경기의 투구·타격 장면에서 확인했습니다. 리플레이, 컷신, 홈런 더비 화면에서 끝이 잘리거나 깜빡이면 이슈로 알려 주세요.
- 실기(PS2 본체)에서는 이 pnach를 쓸 수 없습니다. 실기는 본체 설정의 TV 화면을 16:9로 바꾸면 게임의 원래 와이드 모드가 켜집니다.

| 실행파일 문자열 | UTF-16 문구 약 3,300개, ASCII 문구 약 3,000개. 메뉴·HUD·판정·기록 문구, 메모리 카드 안내 |
| 도움말·매뉴얼 | 도움말 약 840개, 게임 내 매뉴얼 약 1,000개 |
| 프랜차이즈 | 이메일 약 490개, 단장(GM) 메시지 약 290개, 스카우트 리포트 약 900개 |
| 야구 퀴즈 | 문제·보기 약 1,900개 |
| 팀·선수 | 팀 이름 약 970개(약자·도시 제외), 선수 이름 약 2,450개, 한국·일본·대만 선수 전체 이름 22명 |
| 글꼴 | 한글 **1,144자**. 아주 작은 글자는 갈무리11, 나머지는 원본(Arial Bold)과 비슷한 나눔스퀘어 네오 Bold |

영어 전용 게임에 한글을 표시하기 위해 글자 그리기 코드에 **동적 한글 글리프 캐시**를 넣었습니다. 경기 중 그려지는 폰트(Arial Black 17·20, 큰 글씨)는 GS 메모리(VRAM)가 빠듯해 텍스처를 원래 크기로 두고 원래 빈칸만 캐시로 씁니다. 쓰이는 한글만 필요할 때 폰트 텍스처 빈칸에 그려 넣으므로, 빠듯한 메모리 안에서도 1,144자를 쓸 수 있습니다. ASCII 문자열 속 한글은 2바이트로 바꿔 넣고, 실행파일의 ASCII↔유니코드 변환을 고쳐 읽게 했습니다. 자세한 내용은 [docs/TECHNICAL.md](docs/TECHNICAL.md)를 참고하세요.

### 번역 원칙

- 기계 번역 없이 문맥을 보고 직접 번역했습니다.
- 야구 용어는 국내 중계 표기를 따랐습니다: 평균자책점, 마무리, 셋업, 대타, 고의사구, 뎁스 차트.
- 팀 이름은 약자 없이 한글로(양키스, 레드삭스, 화이트삭스), 선수 이름은 국내 MLB 중계 표기와 외래어 표기법을 따랐습니다(예: 테셰이라, 잠브라노).
- 한국·일본·대만 선수는 이치로처럼 성 칸에 전체 이름을 넣어, 목록과 경기 화면에서 잘리지 않게 했습니다(박찬호, 서재응, 추신수, 마쓰이 히데키, 이구치 다다히토, 왕젠밍 등).
- 선수 목록의 이름 첫 글자 표시(예: "S. PODSEDNIK")는 한글로 의미가 없어 빼고 성만 보이게 했습니다.
- 지침은 `translation/STYLE.md`에 있습니다.

### 번역하지 않은 것

- 팀 약자(NYY, BOS 등), 통계·포지션 약어, 도시 이름(구장 데이터를 찾는 열쇠로도 쓰여 바꾸면 멈춤)
- 게임이 모델·구장·유니폼을 찾는 열쇠로 쓰는 한 단어 영문 문자열 일부, 카메라 이름
- 장내 아나운서용 이름 목록, 로고·그림 글자, FMV, 노래·밴드 이름, 크레디트

## 알려진 한계

- v1.0은 흐린 날씨(OVERCAST) 경기에서 로딩 중 화면이 깨지며 멈췄습니다. v1.1에서 고쳤습니다. 다른 구장·날씨 조합에서 멈추면 이슈로 알려 주세요.
- 경기용 큰 글씨 폰트는 한 화면에 서로 다른 한글을 27~40자까지 표시할 수 있습니다. 이보다 많으면 글자가 섞여 보일 수 있습니다.
- 장내 아나운서가 선수 이름을 부르는 기능은 확인하지 못했습니다. 이름 목록을 글자로 찾는다면 한글로 바꾼 선수의 이름을 부르지 않을 수 있습니다.
- 일부 짧은 영문 라벨은 게임 내부 열쇠와 겹쳐 영문으로 남았습니다.
- 모든 화면을 직접 확인하지는 못했습니다. 프랜차이즈 진행, 월드 베이스볼 클래식, 홈런 더비, 온라인 메뉴, 메모리 카드 실제 저장은 확인하지 못했습니다. 칸을 넘치거나 글자가 사라지는 화면이 있으면 이슈로 알려 주세요.
- 인게임 확인은 PCSX2로 했습니다. 실기에서의 동작은 확인하지 못했습니다.
